# VivasayaMart

Tamil farmer-friendly agriculture e-commerce frontend built with HTML, CSS and Vanilla JavaScript.

## Categories
- விதைகள் — 10 products
- இயற்கை உரங்கள் — 10 products
- இயற்கை பூச்சி விரட்டிகள் — 10 products
- விவசாய கருவிகள் — 10 products
- நீர்ப்பாசன பொருட்கள் — 10 products
- பண்ணை காய்கறிகள் — 10 products

Total: 60 products.

## Styling
Only ONE CSS file is used:
`css/style.css`

It contains desktop, mobile responsive, navbar, hero, product, cart, checkout, login/register, about, contact and order styles.

## Images
Placeholder SVG files are included in each category folder. Replace them later with your own images using the same filenames.

`images/hero-farm.svg` is the Home page background placeholder.

## Language
Main website content is Tamil. Navigation and action buttons remain English.

## Run
Open `index.html` in a browser.
